DeepSeek Harness 免安装便携版（Windows）使用说明
================================================

一、这是什么
------------
DeepSeek Harness 的 Windows 免安装版：
内置官方 Node.js 运行时与全部程序包，解压后双击即可使用。

  - 本机无需安装任何软件（Node.js 已内置）
  - 不写注册表、不设环境变量、不改系统设置
  - 所有用户数据（API Key、会话、配置）都保存在本文件夹的 data\ 目录内
  - node_modules 为纯扁平真实目录（零链接），文件夹拷贝、
    ZIP 解压、git clone 后均直接可用
  - 整个文件夹拷贝到任意 64 位 Windows 10/11 电脑即可独立运行，
    换电脑 / 换路径无需任何操作

二、如何启动
------------
方式一（推荐）：双击「启动 DeepSeek Harness.exe」
方式二：在命令行执行
  node.exe node_modules\@deepseek-ai\dsh\lib\bin.js web

启动后会自动打开浏览器访问 http://127.0.0.1:3081
（若未自动打开，请手动在浏览器输入该地址）

关闭方法：关闭启动时出现的黑色命令行窗口，即可停止服务。

若启动失败，会弹出提示窗口并给出排查命令；
若端口已被占用（说明已有实例在运行），会直接打开浏览器而不会重复启动。

三、自定义端口（可选）
---------------------
在本文件夹内新建 port.txt，写入一个端口号（例如 3090），
启动器就会改用该端口，浏览器也会自动打开对应地址。

四、首次使用
------------
1. 打开页面后，按提示配置模型服务（如填写 DeepSeek API Key）
2. Key 只保存在本机本文件夹的 data\ 目录内，不会上传
3. 选择工作区、模型和模式后即可开始对话

五、目录说明
------------
  启动 DeepSeek Harness.exe   一键启动器（双击即用）
  node.exe                   内置 Node.js 运行时（v24.19.0）
  node_modules\              全部程序包（npm 扁平安装，528 包）
  data\                      用户数据（配置、Key、会话；首次启动自动生成）
  package.json               运行时清单（@deepseek-ai/dsh@0.1.0-rc.6）
  LICENSE / THIRD_PARTY_NOTICES.md   许可证与第三方声明
  README.md / 使用说明.txt    使用文档

六、注意事项
------------
- 官方标注 DeepSeek Harness 为开发者预览版，可能快速迭代、有不兼容变更
- Agent 可能修改文件、执行命令，请从测试目录开始使用
- 需要联网使用模型 API 与联网搜索；离线时程序可启动但无法调用模型
- 仅支持 64 位 Windows 10 及以上系统
- 许可证：MIT（见根目录 LICENSE 与 THIRD_PARTY_NOTICES.md）
